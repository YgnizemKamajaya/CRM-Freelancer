# Historical documents

These files preserve earlier plans and design ideas. They are not current implementation instructions. Use [the main README](../../README.md), [contributor guide](../../CLAUDE.md) and [current backlog](../../AUDIT-TODO.md) for ongoing work.

| File | Why it is archived |
| --- | --- |
| [Original audit proposal](01_Original_Audit_Proposal.md) | Some findings were real, but counts, severity and several patches were rejected or changed after independent validation |
| [Product requirements and implementation plan](PRD.md) | Contains old account, schema, dependency and scope examples that no longer match the app |
| [Design guidelines](design-guideline-mini-crm.md) | Contains old Flowbite-based examples and accessibility targets that do not establish current compliance |

Original wording is preserved as history. Terms such as MVP (first usable release), CRUD (create/read/update/delete), SPA (navigation without a full page reload), and DDL (database structure definitions) appear in these old technical plans. Current user guides describe the behavior directly.
